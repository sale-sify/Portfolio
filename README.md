# Portfolio – Romain Sales

## Overview

This is the personal portfolio website of **Romain Sales**, showcasing skills, projects, and design sensibilities built with **Vue.js**, **Vite** and **TypeScript**.  
The site includes an interactive, animated user experience, a project showcase section, and links to deployed applications including a To-Do Manager project.

The portfolio is designed to highlight frontend capabilities, usability, and visual creativity.

---

## Live Demo

The application is live at:  
https://portfolio-rho-one-xl3jc42s9g.vercel.app/

---

## Features

- Fully responsive portfolio layout
- Interactive elements and smooth scroll interactions
- Projects showcase with screenshots and links
- About section to present personal background
- Contact or quick navigation sections
- Deployment via Vercel for global accessibility

---

## Technologies Used

This project was built using:

- **Vue.js 3** – Reactive user interface  
- **TypeScript** – Static typing and robust application code  
- **Vite** – Fast development and build tooling  
- **CSS / Flexbox / Transitions** – Visual styling and animations  
- **Vercel** – Deployment platform for modern JAMstack sites

---

The main entrypoint for the app is `main.ts`, which mounts the Vue application and configures routing and stores.

---

## Getting Started

### Prerequisites

Make sure you have Node.js installed:

```bash
node -v
npm -v
```

### Install the dependencies 

```bash
npm install
```

### Run the project locally 

```bash
node
npm run dev
```
