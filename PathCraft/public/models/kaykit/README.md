# Modèles 3D du plan du jardin (section Infra)

Source : **KayKit Medieval Hexagon Pack 1.0**, par Kay Lousberg (www.kaylousberg.com).
Licence : CC0 (voir `LICENSE.txt`), utilisation libre, attribution non obligatoire mais appréciée.

Dépôt : https://github.com/KayKit-Game-Assets/KayKit-Medieval-Hexagon-Pack-1.0
(fichiers dans `addons/kaykit_medieval_hexagon_pack/Assets/gltf/`)

Seuls les modèles utilisés par `src/data/gardenLayout.ts` sont gardés ici.
Pour en ajouter un : copier son `.gltf` et son `.bin` dans ce dossier (la texture
`hexagons_medieval.png` est commune à tous les modèles), puis l'utiliser dans le plan.
